# Example Images

This directory contains example images for the landing page.

## Required Images

Please add the following three images to this directory:

1. **example1** - "LeBron's UNSTOPPABLE workout? It's NOT what you think..." 
   - Headline slide with pink highlight on "UNSTOPPABLE"

2. **example2** - "Core Strength Focus"
   - Educational slide about core strength with underlined text and pink highlights

3. **example3** - "Mind Over Matter"
   - Mental wellness slide with dark blue text, underlined phrases, and light red highlights

## Image Format

- File names: example1, example2, example3 (with any image extension: .jpg, .png, .webp, etc.)
- Aspect ratio: 9:16 (vertical, Instagram story/carousel format)
- Recommended dimensions: 1080x1920px or similar
